# Private Go broker prototype

This source-only prototype drafts version-2 control parsing, Windows job ownership and child launch. It cannot replace the current PowerShell or C# broker because it has not been built, run or validated against native process behavior. The compiled selector remains off.

The current parser checks the 1,048,576-byte frame budget, 65,536-token and 524,288-decoded-text-byte config budgets, strict UTF-8, exact top-level fields, duplicate JSON keys, JSON value kinds, required scalar values, protocol version, parent PID, argument array and child environment. Its case-folding of environment names is provisional: Go's Unicode uppercasing is not established as equivalent to the C# broker's ordinal-ignore-case comparison. That difference must be resolved with Windows-specific parity cases before this parser can be used for any supervised child.

The source now includes an unbuilt Windows child-launch draft using `syscall.StartProcess`. The installed Go source shows that `exec.Cmd` adds `SYSTEMROOT` to an explicit environment when absent, while the lower-level Windows start path sends a non-nil environment slice through to `CreateProcess` without that addition. The draft retains the returned child process handle for creation identity, job membership and wait, retains the parent handle, claims a kill-on-close job, checks membership before emitting the existing header, and forwards three streams. None of these native paths has been built or exercised. Windows job layout, parent-death behavior, failure cleanup, exact child environment, deadline accounting and complete-tree stop still require proof. The restricted-token diagnostic that produced a Windows error popup remains stopped. This source alone is not performance or write-footprint evidence.
