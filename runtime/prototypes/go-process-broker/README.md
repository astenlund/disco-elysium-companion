# Go process broker

These sources are the release inputs of `runtime/native/go-broker.exe`. `runtime/native/compiled-images.json` binds the packaged binary to exactly `go.mod`, `control.go`, `child_windows.go`, `job_windows.go` and `cmd/go-broker/main.go`, built with `go1.26.0` for `windows/amd64` with `-buildvcs=false -trimpath -ldflags=-buildid=`. Despite the folder name, they are not a sketch: the selected compiled-image chat path launches this binary for every supervised child when its image pins are ready. The compiled selector remains off for players until its acceptance gates pass; see [integrated startup execution](../../../.nightshift/features/runtime-startup-execution-30.md).

`control.go` parses the version-2 control frame with its 1,048,576-byte frame budget, 65,536-token and 524,288-decoded-text-byte config budgets, strict UTF-8, exact top-level fields, duplicate JSON keys, JSON value kinds, required scalar values, protocol version, parent PID, argument array and child environment. `job_windows.go` claims a kill-on-close job that contains the broker itself, and the broker keeps that job handle until it exits, because closing the last handle earlier would end the broker with exit code 0 before it reported the child's code. `child_windows.go` launches the child through `syscall.StartProcess`, retaining the child and parent process handles for creation identity, job membership and wait. The lower-level start path sends a non-nil environment slice to `CreateProcess` without the `SYSTEMROOT` that `exec.Cmd` would add. `control_test.go` covers the control grammar, budgets and environment collisions; `child_windows_test.go` covers the explicit environment, stdin handoff after the control frame and the owned header; `job_windows_test.go` covers job-name admission, and `exit_windows_test.go` runs the test binary as a broker that claims a real kill-on-close job and launches a child exiting with 0, 1 and 7, requiring the broker's own exit code to match each. No unit test checks that closing the job ends a surviving child. `runtime/test/release-go-broker.test.ts` repeats the exit-code check against the packaged `go-broker.exe`.

Two things remain unproved and are acceptance gates for enabling the selector. First, environment names are compared by `strings.ToUpper`, and parity with the PowerShell broker's ordinal-ignore-case comparison is tested only for ASCII names. Second, behavioural parity with the PowerShell broker it replaces, covering the control grammar, child environment, deadline accounting and complete-tree stop, has not been established. Private copied-root fixtures have exercised launch, job membership and verified stop through this binary, as recorded in [selected-image fixture evidence](../../../.nightshift/reports/runtime-selected-image-fixture-evidence-20261019.md), but that is exercise, not a parity proof.
