# Private held-image identity probe, 2026-10-18

On private branch `codex/fast-startup-production`, ignored `handle-identity-20261018/run-b/result.json` records a copied-binary control for the fixed Go broker and native observer. The probe opened each executable with `GENERIC_READ` and `FILE_SHARE_READ`, read its final path, volume, file ID, link count and attributes from that handle, matched those values to a fresh `NativeFiles.AdmitWithin` result, and hashed through the held handle with a finite read bound. Both expected binary hashes matched. Same-user write opens and executable renames failed with sharing refusals while the handles remained open; an ancestor rename also failed. After closure, write opens and executable and ancestor renames succeeded. This is an observed control, not proof against privileged replacement or every ancestor independently.

The separate `run-c/result.json` control admitted a broker copy, moved it aside, then copied identical bytes back under the same name before opening the handle. The new handle reported the same path and SHA-256 but a different file ID from the prior admission; the mismatch was detected. This makes volume and file ID comparison necessary in addition to a path and hash check when binding a selected image to its admission. The probe source and sanitized launcher are under `.tmp/handle-identity-20261018/`; their fixture writes target this private worktree. A whole-process write audit was not run.

In `run-d/result.json`, a handle opened on the live Node parent with `PROCESS_DUP_HANDLE` and `PROCESS_QUERY_LIMITED_INFORMATION` returned a creation FILETIME matching the expected token; an altered token was refused against the same opened process handle. The control does not simulate PID reuse or transfer a file handle to that process.

These probes do not establish remote duplicated-handle readback, abrupt-failure release, complete process-tree write containment, compiled artifact installation provenance, production selection or real-provider timing. Ordinary CLI chat remains on its existing path and the 30-second goal remains open.
