# Private executable image gap, 2026-10-18

The `codex/fast-startup-production` branch contains private adapters for a Go process broker and a native job observer. Ordinary `node runtime/src/cli.ts chat` still selects PowerShell. The copied-root fake-provider result on the source branch was 27.237 seconds for one new-save start and 19.554 seconds for one acknowledged restart, but neither result proves a real-provider 30-second start or makes the adapters eligible for production selection.

A fresh GPT-6 Sol code review found, and an independent GPT-6 Sol skeptic confirmed, that each private executable is hashed through an open Node read descriptor and then launched by pathname. The read descriptor does not exclude a concurrent write or rename on Windows. The post-close path check can refuse the result, but cannot undo bytes already executed. The same gap applies to the broker paths in `compiled-broker.ts` and `go-broker-artifact.ts`, and the observer `execFile` in `process.ts`. This is an Important candidate blocker, not a claim that ordinary chat currently exposes the private selector. The relevant source behavior is documented by [libuv Windows fs_open](https://github.com/libuv/libuv/blob/v1.x/src/win/fs.c) and [Windows CreateFile sharing rules](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilea).

A separate repository-local seal probe copied the fixed SHA-256 `aa52d71f8a2243bdcb83bc394a12fe8193e413eb70b3543130f69df5a99c5d13` broker into `.tmp/artifact-seal-20261018/run-b/sealed/`. Its result records that the same user could not open the file for writing, delete or rename it, create a sibling, or change the file or leaf-directory DACL, while Windows launched the binary and it exited 125 on empty control input. `run-c` also observed refusal to rename the sealed leaf directory. The separate `run-d/ancestor-rename.json` records that its unsealed parent directory could be renamed and restored while retaining the binary hash. These probes establish only those observed operations for this user and these paths. They do not establish complete ancestor immutability, executed-image identity, or resistance to privileged override.

The shared private-file reader was separately changed to cap allocations at the admitted size plus one byte and to parse the observer manifest from the pinned descriptor. The private artifact contract test, native owned-process test, process transport and failure tests, TypeScript type check, and a new combined Go broker plus native observer fixture passed after that change. Those checks address bounded reads, not the launch gap. No real consumer command, real provider, or original SaveGames write was used in this investigation. The 30-second healthy-start goal remains open; production selection and live SDK timing remain gated by the approved startup design's private negative paths, direct source and write proof, independent final review, and user-coordinated live measurement.
